# Security and corrections

This repository contains an adaptable penetration-testing practice framework: methods, guides, templates, examples, native worksheets, decks, and diagrams. It is not a running service or a penetration-testing tool. Please use GitHub issues for corrections to the public material. Do not post credentials, customer details, restricted reports, or live exploit evidence. For a sensitive report, email hello@robhunterworks.com rather than opening a public issue.
