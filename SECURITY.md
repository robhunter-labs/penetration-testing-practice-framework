# Security and corrections

This repository contains an adaptable penetration-testing practice framework: methods, guides, templates, examples, native worksheets, decks, and diagrams. It is not a running service or a penetration-testing tool. Please use GitHub issues for corrections to the public material. Do not post credentials, customer details, restricted reports, or live exploit evidence. To report a potential vulnerability or a sensitive problem in these files, use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it, and don't post secrets or exploit details anywhere public. If private reporting ever appears unavailable, email hello@robhunterworks.com.
