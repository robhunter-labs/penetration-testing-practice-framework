# Security and corrections

This repository contains an adaptable penetration-testing practice framework: methods, guides, templates, examples, native worksheets, decks, and diagrams. It is not a running service or a penetration-testing tool.

**Corrections and adaptation notes.** Please use GitHub issues for the public material: a [correction](https://github.com/robhunter-labs/penetration-testing-practice-framework/issues/new?template=correction.yml) when something is wrong, outdated, or unclear, and an [adaptation note](https://github.com/robhunter-labs/penetration-testing-practice-framework/issues/new?template=adaptation.yml) to share how a component fit your team or where it didn't. [CONTRIBUTING](.github/CONTRIBUTING.md) has the ground rules. Do not post credentials, customer details, restricted reports, or live exploit evidence.

**Sensitive reports.** To report a potential vulnerability or a sensitive problem in these files, use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for it, and don't post secrets or exploit details anywhere public. If private reporting ever appears unavailable, email hello@robhunterworks.com.
